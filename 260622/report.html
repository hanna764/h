2026 연내로스트소드 대만/홍콩/마카오엔씨타이완 퍼블(遺忘之劍)
2026 하반기미래시컨트롤나인 / 스마일게이트
2026말~2027초귀환(Rewinding Cadence)텐센트 Saroasis, 타임루프 오픈월드 ARPG

글로벌 확장 이슈

  • CN 라이브 게임 KR 매출 톱 점유 확대: W26에 명조가 6월 KR 서브컬처 매출 1위 등극 — 단기 이벤트가 아닌 구조적 변화 가능성. 하반기 무한대·귀환까지 진입 시 KR 톱 슬롯의 CN 점유 고착화 우려.
  • 대만 시장: 호요 3종 + 니케 + FGO 강세 유지. 로스트소드 중화권 진출(연내)로 KR산 서브컬처의 TW 확장 시도.
  • 멀티플랫폼화: 이환·엔드필드·젠레스(Steam 6/17)·무한대(PS5) 등 PC·콘솔 동시 서비스 보편화 가속.

시장 구조 트렌드

  • 외부 IP 콜라보 트렌드 재가동: 명조×사이버펑크(흥행) + 벽람×니어 오토마타(W26 발표) — 콜라보의 신규·복귀 유입 견인력이 재입증되며 라이브 게임의 핵심 모멘텀 엔진으로 정착.
  • 대형 KR사 서브컬처 진입 본격화: 엔씨·스마일게이트·넷마블 라인업 진행 — 국산 라인업 다변화 + KR 마케팅/인력 경쟁 격화.
  • 오프라인 접점 강화: 우마무스메 4주년 KINTEX 페스티벌 사례처럼 코어 팬덤 오프라인 접점이 라이브 운영의 핵심 요소로 부상.

5 브더2(BrownDust 2) 관점 시사점

BD2 — 네오위즈의 2D 스토리·코스튬 기반 서브컬처 수집형 RPG / 글로벌 서비스 중

위협 요인

1. KR 서브컬처 매출 톱 슬롯이 CN(명조)으로 이동 — 구조적 신호
W26 핵심 변화: 명조가 6월 KR 서브컬처 매출 1위 등극(니케 4주년 종료 후). 명조 단발 이슈가 아니라 무한대·귀환·아주르프로밀리아 등 CN 라인업 대기 흐름과 결합 시 KR 톱 슬롯의 CN 점유 고착화 가능성. BD2의 KR 매출 톱티어 경쟁 구도 재점검 시점.
2. 6/17 KR 라이브 업데이트 8종 동시 진행 — 주간 가챠·플레이타임 정점 경쟁
블아 산해경·몬길 나기·림버스 발푸르기스 8회·벽람 KR 정기·로스트소드 6/18·트릭컬 6/20·이터널리턴 11.4 동시 진행. 코어 유저의 주간 가챠 예산·플레이타임이 정점 분산 → BD2 신규 코스튬·이벤트 흡수 압박.
3. 6/24 스타레일 Phainon · 6/25 붕괴3rd 8.9 호요 더블 픽업
호요 라인업의 6월 말 매출 흡수가 정점에 도달. 7월 1주차 BD2 매출/지표 압박 가능.
4. 외부 IP 콜라보 트렌드 강화 — 벽람×니어 오토마타 사례
명조×사이버펑크 흥행 후 벽람×니어 오토마타 확정 발표(6/18) — 라이브 게임의 핵심 모멘텀 엔진으로 외부 IP 콜라보가 굳어지는 추세. BD2 콜라보 라인업 부재 시 신규·복귀 견인력 격차 확대.
5. 국산 서브컬처 라인업 진행
엔씨 LZB(연내), 스마일게이트 미래시·카오스제로, 넷마블 몬길 STAR DIVE 라이브 — 국산 경쟁 강도 누적. BD2의 KR 점유·인지도 경쟁 심화.

기회 요인

1. 명조 콜라보 종료(7/9) 직전·직후 이탈 유저 흡수 골든타임
사이버펑크 콜라보 종료 직후 신규·복귀 유저 이탈이 발생할 7월 1~2주차가 BD2의 핵심 흡수 구간. BD2 신규 코스튬·복귀 이벤트를 7월 초에 선제 배치 권장.
2. 외부 IP 콜라보 라인업 검토 적기
벽람×니어 사례로 외부 IP 콜라보 견인력 재입증 — BD2도 화제성 높은 글로벌 IP 콜라보 라인업 검토 적기. 외부 IP 콜라보 부재가 신규/복귀 유입 견인력 차이로 굳어지기 전 선제 대응 필요.
3. 2D 스토리·코스튬 차별화 소구
CN 3D 오픈월드(이환·엔드필드·무한대 대기) 피로 + 호요 신규 캐릭터 의존도 누적 시점에 BD2의 2D 작화·컷신 스토리·코스튬 IP 차별점 강조. 호요·CN 라인업 사이에서 '가볍고 깊은' 포지션 확보.
4. 오프라인 접점 검토 (우마무스메 KINTEX 페스티벌 모델)
우마무스메 4주년 KINTEX 페스티벌(6/13) 사례 — 라이브 게임의 코어 팬덤 오프라인 접점이 라이브 운영의 핵심 요소로 부상. BD2도 쇼케이스·팝업·콜라보 카페 등 오프라인 접점 검토 권장.
5. 신작 출시 러시(8~12월) 전 충성 유저 기반 공고화
아주르프로밀리아·무한대·리밋제로 등 대형 신작이 하반기 대거 진입 예정. 신작 러시 전 7~8월에 BD2 충성 유저 기반·과금 동선·콜라보 라인업을 선제 강화하는 것이 최우선 과제.
