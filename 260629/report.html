  • CN 라이브 게임 KR 매출 톱 점유 확대 신호: 명조가 6월 KR 구글플레이 종합 매출 1위를 2주(W26·W27) 연속 유지 — 단기 이벤트가 아닌 구조적 변화 가능성. 하반기 무한대·귀환까지 진입 시 KR 톱 슬롯의 CN 점유 고착화 우려.
  • 대만 시장: 호요 3종 + 니케 + FGO 강세 유지. 로스트 소드 중화권 진출(연내)로 KR산 서브컬처의 TW 확장 시도.
  • 멀티플랫폼화: 이환·엔드필드·젠레스(Steam 6/17 정식) 등 PC·콘솔 동시 서비스 보편화 가속.

시장 구조 트렌드

  • 외부 IP 콜라보 트렌드 재가동: 명조×사이버펑크(흥행) → 벽람×니어 오토마타(7/1 1차 정보 공개) — 콜라보의 신규·복귀 유입 견인력이 재입증되며 라이브 게임의 핵심 모멘텀 엔진으로 정착.
  • 대형 KR사 서브컬처 진입 본격화: 엔씨·스마일게이트·넷마블 라인업 진행 — 국산 라인업 다변화 + KR 마케팅/인력 경쟁 격화.
  • 오프라인 접점 강화: 라이브 게임의 코어 팬덤 오프라인 접점(쇼케이스·팝업·페스티벌 등)이 라이브 운영의 핵심 요소로 부상하는 흐름 — BD2 콜라보·쇼케이스 검토 적기.

5 브더2(BrownDust 2) 관점 시사점

BD2 — 네오위즈의 2D 스토리·코스튬 기반 서브컬처 수집형 RPG / 글로벌 서비스 중

위협 요인

1. 6/24 스타레일 Phainon · 6/25 붕괴3rd 8.9 호요 더블 픽업이 6월 말 매출 흡수 정점
호요 라인업의 6월 말 KR/TW 매출 흡수가 정점에 도달, BD2 월말 결산 압박. 특히 Phainon은 7/15까지 배너 운영, 8.9는 8/20까지 신규 콘텐츠 가동되며 7월 호요 모멘텀 지속 우려.
2. 명조 6월 KR 매출 1위 2주 연속 유지 — CN 톱 슬롯 점유 고착화 신호
W26→W27 2주 연속으로 명조가 6월 KR 구글플레이 종합 매출 1위 유지. 무한대(Q3말)·아주르프로밀리아(하반기)·귀환(2026말~2027초) 등 CN 라인업이 줄줄이 진입 예정으로 KR 톱 슬롯의 CN 점유가 구조적으로 고착화될 가능성. BD2의 KR 매출 톱티어 경쟁 구도 재점검 시점.
3. 7월 첫 주 라이브 갱신 종료 러시 — BD2 신규 콘텐츠 타이밍 정렬 필요
6/30 원신·카오스제로 · 7/2 니케 · 7/8 이환 · 7/9 명조 콜라보 · 7/15 스타레일 Phainon 종료가 7월 첫 두 주에 누적. BD2의 7월 신규 콘텐츠 출시 타이밍이 이 종료 구간과 어긋나면 유저 흡수 골든타임을 놓칠 수 있음.
4. 외부 IP 콜라보 트렌드 강화 — 벽람×니어 1차 정보 7/1 공개 예정
명조×사이버펑크 흥행 후 벽람×니어 오토마타가 7/1 1차 정보 공개로 화제성 점화 예정 — 외부 IP 콜라보가 라이브 게임의 핵심 모멘텀 엔진으로 굳어지는 추세. BD2 콜라보 라인업 부재 시 신규·복귀 견인력 격차 확대 가속.
5. 국산 서브컬처 라인업 진행
엔씨 LZB(연내), 스마일게이트 미래시·카오스제로, 넷마블 몬길 STAR DIVE 라이브 — 국산 경쟁 강도 누적. BD2의 KR 점유·인지도 경쟁 심화.

기회 요인

1. 7월 첫 주 종료 러시 = CN 가챠 이탈 유저 흡수 골든타임
이환 1.1 종료(7/8) + 명조 사이버펑크 콜라보 종료(7/9) + 원신 6.6 종료(6/30)가 동시에 누적되는 7월 첫 주가 BD2의 핵심 흡수 구간. 7월 초 BD2 신규 코스튬·복귀 이벤트·픽업 슬롯을 선제 배치하면 CN 가챠 이탈 유저의 BD2 흡수 가능성.
2. 호요 모멘텀 일시 둔화 구간 활용
6월 말 호요 더블 픽업이 정점인 만큼, 7월 중순 Phainon 종료(~7/15) 이후 호요 픽업 사이 일시 둔화 구간을 BD2 신규 픽업·이벤트의 우선 슬롯으로 노릴 수 있음.
3. 외부 IP 콜라보 라인업 검토 적기
벽람×니어 1차 정보 공개(7/1) + 명조×사이버펑크 흥행 사례로 외부 IP 콜라보 견인력 재입증 — BD2도 화제성 높은 글로벌 IP 콜라보 라인업 가시화 적기. 외부 IP 콜라보 부재가 신규/복귀 유입 견인력 차이로 굳어지기 전 선제 대응 필요.
4. 2D 스토리·코스튬 차별화 소구
CN 3D 오픈월드(이환·엔드필드·무한대 대기) 피로 + 호요 신규 캐릭터 의존도 누적 시점에 BD2의 2D 작화·컷신 스토리·코스튬 IP 차별점 강조. 호요·CN 라인업 사이에서 '가볍고 깊은' 포지션 확보.
5. 오프라인 접점 검토
라이브 게임의 코어 팬덤 오프라인 접점(쇼케이스·팝업·콜라보 카페·페스티벌 등)이 라이브 운영의 핵심 요소로 부상하는 흐름이 지속. BD2도 쇼케이스·팝업·콜라보 카페 등 오프라인 접점 검토 권장.
6. 신작 출시 러시(8~12월) 전 충성 유저 기반 공고화
아주르프로밀리아·무한대·리밋제로·귀환 등 대형 신작이 하반기 대거 진입 예정. 신작 러시 전 7~8월에 BD2 충성 유저 기반·과금 동선·콜라보 라인업을 선제 강화하는 것이 최우선 과제.
